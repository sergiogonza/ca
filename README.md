# Camellando

Directorio de talento, oficios y servicios.

## Stack

- Gatsby 5
- React 18
- Emotion 11
- Netlify adapter
- Node 22

## Rutas

- `/` Directorio
- `/publicar` Publicar perfil
- `/admin` Moderación

## Desarrollo

```bash
npm install
npm run develop
```

## Producción

```bash
npm run build
```
